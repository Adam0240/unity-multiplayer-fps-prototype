# Multiplayer FPS Prototype

Originally developed as a 2-person collaborative project at Aiken Technical College.

I led the core technical implementation, including:
- full map and terrain design
- player setup and movement systems
- multiplayer lobby UI and client connection flow
- LAN multiplayer integration
- gameplay system integration
- Windows build deployment and validation

Collaborative contributions:
- Andrew Odom: weapon design and implementation, original background music, and supporting gameplay systems

This project was recently reopened, rebuilt, and revalidated to confirm that multiplayer sessions still function across connected clients.
